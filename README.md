# dcacbimithl-standup-bot
In the game 'Case and Clown Bot in: Murder in the Hotel Lisbon' there is a stand up mini game for clown bot, i and was just curious how to solve it by code. Here is the solution. 

Game maker have big map at 0x891580 so whole trick starts from that. Other offsets was found in ghidra. 

# Run
1. Download releases (or build yourself).
2. Strat game open stand up show
3. Run .exe

java Build.java
